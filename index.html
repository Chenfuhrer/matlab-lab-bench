    4.1带点和不带点

    MATLAB 默认按线性代数的规则做乘、除、乘方。想让对应位置的元素逐个运算，就在运算符前加一个点。

    矩阵运算含义逐元素运算含义
    A * B矩阵乘法，A 的列数 = B 的行数A .* B对应元素相乘
    A / B右除，解 xB = AA ./ B对应元素相除
    A \ b左除，解 Ax = bA .\ BB 的元素除以 A 的元素
    A ^ 2A*A，要求方阵A .^ 2每个元素平方
    A'共轭转置A.'普通转置（复数时有区别）

    加减法本来就是逐元素的，不需要点。

    易错

    写信号表达式时最容易犯这个错：exp(-t) * sin(t) 在 t 是向量时会报错，要写 exp(-t) .* sin(t)。同理 t^2 要写成 t.^2，1/t 要写成 1./t。

    4.2隐式扩展

    从 R2016b 开始，尺寸不同的数组做逐元素运算时，如果某一维长度为 1，就会自动沿这一维复制。用它可以一行完成“每列减去该列均值”这类操作。

    9.3卷积：别忘了时间轴

    conv 只管数值，不知道序列从哪个 n 开始。结果的起点等于两个序列起点之和，终点等于两个终点之和，长度是两者长度之和减 1。

    9.4差分方程与 filter

    filter(b, a, x) 求解差分方程 a(1)y[n] + a(2)y[n−1] + … = b(1)x[n] + b(2)x[n−1] + …。输入单位冲激，得到的就是单位冲激响应 h[n]。

    9.5频谱分析：fft 与频率轴

    对 N 个采样点做 fft，得到 N 个复数。第 k 个点（下标从 1 开始）对应的频率是 (k−1)·fs/N，前一半是 0 到 fs/2 的正频率。幅度要除以 N；画单边谱时，除直流外再乘 2。

    易错

    频谱峰的位置不对，十有八九是频率轴写错了：写成了 (1:N)*fs/N，或者把 fs 和 N 搞反。另外，信号频率不落在 fs/N 的整数倍上时，能量会泄漏到相邻频点，峰值会变矮、变宽，这不是代码错误。

    10.2非线性拟合

    模型不是多项式时（比如指数增长 y = a·ebt），用 lsqcurvefit 直接拟合参数。初值要大致靠谱，否则可能收敛到奇怪的地方。

    10.3插值

    拟合要求曲线“整体靠近”数据，插值要求曲线必须经过每个数据点。补全缺测数据、加密采样时常用插值。

    10.4线性规划 linprog

    某厂生产两种产品，单件利润分别为 3 和 5（千元）。三个车间的工时约束为 x₁ ≤ 4，2x₂ ≤ 12，3x₁ + 2x₂ ≤ 18。求利润最大的生产方案。

    linprog 的标准形式是 min f′x，s.t. Ax ≤ b，Aeq·x = beq，lb ≤ x ≤ ub。求最大值就把目标系数取负。

    10.5整数规划 intlinprog

    决策变量必须取整数时（人数、车辆数、是否选择某项目），用 intlinprog，第二个参数列出哪些变量是整数。下面是一个 0-1 背包问题：容量 15，选哪些物品价值最大。

    10.6非线性规划 fmincon

    目标或约束是非线性的，用 fmincon。非线性约束写成一个函数，返回 c(x) ≤ 0 和 ceq(x) = 0 两部分。

    说明

    实验台的 fmincon 用增广拉格朗日法配合单纯形搜索近似求解，适合几个变量的小问题，结果和 MATLAB 可能在小数点后几位有差异。正式比赛请在本地 MATLAB 中运行，并换几个初值 x0 检查是否得到同一个解。

    10.7微分方程：SIR 传染病模型

    S、I、R 分别是易感者、感染者、康复者人数，β 是感染率，γ 是康复率：dS/dt = −βSI/N，dI/dt = βSI/N − γI，dR/dt = γI。ode45 要求把方程写成“状态向量的导数 = f(t, y)”的形式。

    易错

    函数 f 必须返回列向量，长度和初值 y0 一样。二阶方程要先降阶：y″ + 0.5y′ + 4y = 0 写成 @(t, y) [y(2); -0.5*y(2) - 4*y(1)]。

    10.8综合评价：熵权法 + TOPSIS

    评价类问题（选址、方案排序、绩效评估）的常用组合：熵权法根据数据离散程度确定指标权重，TOPSIS 按到正、负理想解的距离排序。整个流程都是矩阵运算，正好练习隐式扩展。

    数模提示

    成本型指标（越小越好）要先正向化，比如 (max(x) - x) ./ (max(x) - min(x))。论文里要写清楚每一步的公式，并给出权重表；评委最关心的是权重是否合理、结果是否稳定，最好补一个灵敏度分析。

    10.9灰色预测 GM(1,1)

    数据少（通常 4 到 10 期）而又要做短期预测时，常用 GM(1,1)。步骤是：累加生成、构造背景值、最小二乘估计参数 a、b，再还原预测值。

    10.10读写数据文件（需要本地 MATLAB）

    浏览器里的实验台读不到电脑上的文件。练习时可以先把数据复制进代码，写成矩阵：
data = [1 2.1; 2 3.9; 3 6.2];

    对下面的数据做二次多项式拟合，系数存进 p，并计算拟合优度存进 R2。

    常见报错对照

    MATLAB 的报错信息其实写得很具体，读懂了就知道错在哪。下表左边是英文原文，下面一行是中文版 MATLAB 里大致的说法（不同版本措辞略有差异）。点「复现」会把一段会出这个错的代码放进命令行窗口。

    报错信息常见原因与改法
    Index exceeds the number of array elements. Index must not exceed 3.
    索引超出数组元素的数目。索引不能超过 3。
    		下标比数组长度大。常见于循环上限写错，比如 for k = 1:n+1，或者在 x(k+1) 里越界。用 numel 检查长度。
    Array indices must be positive integers or logical values.
    数组索引必须为正整数或逻辑值。
    		用了 0、负数或小数做下标。MATLAB 从 1 开始数；计算出来的下标用 round 处理。也可能是把变量名起成了 i、sum 之类，被当成了索引。
    Incorrect dimensions for matrix multiplication. Check that the number of columns in the first matrix matches the number of rows in the second matrix. To operate on each element of the matrix individually, use TIMES (.*) for elementwise multiplication.
    用于矩阵乘法的维度不正确。请检查并确保第一个矩阵中的列数与第二个矩阵中的行数匹配。要单独对矩阵的每个元素进行运算，请使用 TIMES (.*) 执行按元素相乘。
    		想逐元素相乘却写了 *。改成 .*；同理 / 改 ./，^ 改 .^。
    Arrays have incompatible sizes for this operation.
    对于此运算，数组的大小不兼容。
    		逐元素运算的两个数组尺寸对不上，比如 1×3 和 1×4。检查是不是两个向量的采样点数不同，或者一个是行一个是列。
    Unrecognized function or variable 'x'.
    函数或变量 'x' 无法识别。
    		变量还没赋值就用了，或者名字拼错、大小写不一致。也可能是缺工具箱，或者自己写的函数文件不在当前文件夹。
    Dimensions of arrays being concatenated are not consistent.
    要串联的数组的维度不一致。
    		用方括号拼接时行数或列数对不上，比如 [1 2; 3]。
    Unable to perform assignment because the left and right sides have a different number of elements.
    无法执行赋值，因为左侧和右侧的元素数目不同。
    		想把一个向量塞进单个位置，比如 x(k) = [1 2]。检查等号右边的结果是不是标量；要存向量就用矩阵的一行 X(k, :) = … 或元胞 c{k} = …。
    Vectors must be the same length.
    向量长度必须相同。
    		plot(x, y) 的 x 和 y 点数不同。常见于 t = 0:0.01:1 和另一个用 linspace 生成的向量混用。
    Not enough input arguments.
    输入参数的数目不足。
    		调用函数时少给了参数。也常见于直接点“运行”一个需要输入的函数文件：函数要在命令行里带参数调用。
    Too many output arguments.
    输出参数太多。
    		把没有返回值的函数写在了等号右边，或者要了比函数定义更多的输出。
    Invalid expression. Check for missing multiplication operator, missing or unbalanced delimiters, or other syntax error.
    表达式无效。请检查缺失的乘法运算符、缺失或不对称的分隔符或者其他语法错误。
    		括号不成对，或者把 2*x 写成了 2x。另一大来源是中文标点：，、；、（）、中文引号。
    Warning: Matrix is singular to working precision.
    警告：矩阵为奇异工作精度。
    		系数矩阵不可逆（行列式为 0 或接近 0），方程组无解或有无穷多解。检查方程是否列重复了，或者用 rank 看矩阵的秩。
    At least one END is missing. The statement beginning here does not have a matching end.
    此语句缺少对应的 END。
    		if、for、while、switch、function 少了 end。养成写完开头立刻补上 end 的习惯，MATLAB 编辑器的自动缩进也能帮你发现。
